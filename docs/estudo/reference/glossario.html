Referência · termos usados nas aulas

Glossário

As aulas usam estes termos sempre com este sentido.

AWS Budgets
O serviço de alertas de gasto da AWS. Um alerta só manda e-mail quando o gasto real ou o previsto passa do valor; ele não desliga nada. É grátis e vem antes de qualquer recurso. O modelo "custo mensal" exclui créditos e reembolsos, então mede o uso antes do crédito. Aula 0011
AWS Builder ID
A identidade pessoal com que se entra numa conta da experiência "AWS (new)". É ela que tem o MFA e que faz o aws login; ela substitui o root e o usuário IAM do roteiro original. Aula 0011 (registro 0013)
Backend (Terraform)
Onde o Terraform guarda o state. O do EduRAG é o s3, com use_lockfile = true. Ele é configurado no bloco terraform e ligado pelo init. Aula 0012
Bypass list
Quem pode ignorar as regras de um ruleset. No protege-main, fica vazia. Aula 0001
Advisory (aviso de segurança)
O registro público de uma vulnerabilidade, com versões afetadas e corrigidas. Identificado por GHSA-… (banco do GitHub) ou CVE-… (catálogo público). Aula 0004
Autenticação × autorização
Autenticação responde "quem é você?" (login, chave). Autorização responde "você pode mexer nisto?" (o documento é seu?). Falha na primeira é a API2 da OWASP; falha na segunda, a API1. Aula 0009
Check obrigatório (required status check)
Um job da CI que precisa ficar verde para o merge ser liberado. É identificado pelo id do job no workflow. Aula 0001
Cadeia de suprimentos (supply chain)
Tudo o que o seu código usa e não foi você que escreveu: bibliotecas, imagens base e actions. Um ataque a qualquer elo chega até você. Aula 0003 (detalhe na etapa 6)
Consumo irrestrito de recursos
A API4 do OWASP API Top 10 (2023): a API não limita o quanto cada cliente gasta de CPU, memória, disco ou serviço pago por requisição. No EduRAG, o serviço pago é o Claude. Aula 0009
Conjunto de regras do Semgrep
Um pacote de regras do registro do Semgrep, como p/default. O Semgrep o chama de ruleset, mas nesta trilha ruleset é só o do GitHub. Aula 0003
Credencial temporária
Uma credencial da AWS que expira sozinha. O aws login entrega uma válida por até 12 horas, a partir do login no console. É o contrário da access key, que vale até alguém apagá-la. Aula 0011
Cooldown
Uma espera mínima, em dias, antes de aceitar uma versão recém-publicada. No uv é o exclude-newer; no Dependabot, a opção cooldown, que só vale para atualizações de versão. Aula 0005
Defesa em profundidade
Mais de uma camada contra o mesmo risco, para que a falha de uma não deixe passar. Ex.: o Semgrep (missing-user) e o id -u barrando a imagem que roda como root. Aula 0006
DAST
Dynamic Application Security Testing: testa a aplicação rodando, de fora, como um atacante faria. Aula 0003
Entropia
O quanto um texto parece aleatório. O gitleaks a usa para separar chaves reais de textos comuns que casam com a mesma expressão regular. Aula 0002
Falso positivo
Um achado de ferramenta de segurança que não é problema de verdade. Só deve ser suprimido com uma justificativa escrita. Aula 0002
Fingerprint
A identificação única de um achado do gitleaks (commit:arquivo:regra:linha). É o que vai no .gitleaksignore. Aula 0002
IaC (infraestrutura como código)
Descrever servidores, redes e permissões em arquivos versionados, e não em cliques no console. No EduRAG, é o Terraform em infra/: o que nasce pelo apply some pelo destroy. Aula 0011
Import (Terraform)
Trazer para o state um recurso que já existe na conta, sem recriá-lo. O bloco import diz o endereço no código (to) e o ID na AWS (id). O plan -generate-config-out escreve um rascunho do HCL, que você limpa antes do git. Aula 0014
IMDSv2
A versão do serviço de metadados da instância que exige um token de sessão antes de responder. No Terraform, é metadata_options { http_tokens = "required" }. O trivy config da aula 0014 cobra essa linha. Aula 0013
Instance profile
O "envelope" que entrega uma role do IAM a uma instância EC2. A instância recebe o nome do profile, e o profile aponta para a role. No EduRAG, a role tem só a AmazonSSMManagedInstanceCore. Aula 0013
Imagem base
A imagem do primeiro estágio de um FROM (por exemplo python:3.12-slim). Traz o sistema operacional, e é dele que vêm os pacotes que o trivy image escaneia. Aula 0006
Limite de taxa (rate limiting)
Um máximo de requisições (ou tokens) por intervalo de tempo, por cliente. Protege contra rajadas, mas não contra um gasto lento e constante: para isso existem a cota e o teto de gastos. Aula 0009
Lock file do provider (.terraform.lock.hcl)
Gravado pelo init com a versão e os hashes de cada provider. Vai para o git, como o uv.lock. Por padrão, só tem os hashes da plataforma onde rodou; terraform providers lock -platform=... acrescenta outras. Aula 0012
Misconfiguration (configuração insegura)
Um achado na configuração, e não numa versão de pacote: porta aberta, disco sem cifra, IMDSv1. É o que o trivy config procura no Terraform. Cada regra tem um ID (AWS-0107) e uma severidade. Aula 0014
MFA
Autenticação multifator: além da senha, uma segunda prova (chave de acesso ou código de app). Obrigatória na identidade que entra na conta: no EduRAG, o AWS Builder ID. Aula 0011
Menor privilégio
Dar a cada peça só as permissões de que ela precisa. Num workflow, é o bloco permissions. Aula 0002
Multi-stage build
Dockerfile com vários FROM: só o último vira a imagem entregue. Os estágios anteriores (Node, uv) só passam arquivos adiante por COPY --from. Aula 0006
Modelo de ameaça
A lista de quem pode atacar, por onde e com que prejuízo, feita antes de escolher os controles. Na etapa 9, é a tabela "o que um visitante consegue fazer hoje". Aula 0009
Modo estrito
A regra "Require branches to be up to date": a branch do PR precisa estar atualizada com a main antes do merge. Aula 0001
Não-root
Um contêiner cujo processo roda com um usuário comum (uid diferente de 0). A checagem confiável é executar id -u dentro da imagem: 0 é root. Aula 0006
Plan × apply
terraform plan compara o código, o state e a conta, e só mostra o que mudaria. terraform apply executa a mudança. Todo apply começa pela leitura do plan. Aula 0011
Plano gratuito (AWS)
O plano das contas criadas a partir de 15/07/2025: até US$ 200 em créditos, 6 meses ou até acabarem, sem passar do limite, só com os tipos de instância elegíveis. Criar uma AWS Organization passa a conta para o plano pago. A conta do EduRAG tem US$ 100 de crédito. Aula 0011
Projeto (experiência "AWS (new)")
Uma conta da AWS criada e governada pela própria AWS, dentro de uma Organization que você não administra. Tem região fixa pelo país (us-east-2 para o Brasil) e SCPs que não podem ser mudadas. O do EduRAG é o "Next Big Thing". Aula 0011 (registro 0013)
Portão (gate)
Uma verificação que bloqueia, e não só avisa. Uma ferramenta vira portão quando o job dela entra nos checks obrigatórios. Aulas 0001, 0002
prevent_destroy
Um item do lifecycle de um recurso: qualquer plano que apagaria o recurso falha com "Instance cannot be destroyed". No EduRAG, protege o Budget. Para largar o recurso sem apagar, usa-se o bloco removed com destroy = false. Aula 0014
Provider (Terraform)
O plugin que traduz os blocos do Terraform em chamadas à API de um serviço. Aqui, o hashicorp/aws, fixado por versão. Aula 0011
Root module (Terraform)
A pasta onde você roda init, plan e apply. Cada root module tem o próprio state. No EduRAG são dois: infra/ (destruído a cada sessão) e infra/conta/ (o Budget, que fica). Aula 0014
Root (conta da AWS)
A identidade criada com a conta, com poder total, que as políticas do IAM não limitam. Fica com MFA, sem access key, e só entra para tarefa que só ele faz. O dia a dia é com um usuário IAM. Num projeto da experiência "AWS (new)", não existe root: o dono é o AWS Builder ID. Aula 0011
Scope (do cache do Buildx)
O nome do cache de camadas no type=gha. Builds que dividem o mesmo scope sobrescrevem o cache um do outro; use um por imagem. Aula 0006
Registro (registry)
O servidor que guarda imagens de contêiner para serem baixadas, como o GHCR (ghcr.io) e, mais tarde, o ECR da AWS. Aula 0008
Revogar
Invalidar uma chave no serviço que a emitiu. É o primeiro passo diante de um segredo vazado. Aula 0002
Ruleset
Uma lista nomeada de regras que o GitHub aplica a branches escolhidas. Vários rulesets se somam. Aula 0001
SARIF
Formato JSON padronizado para resultados de análise estática. É o que a aba Security → Code scanning do GitHub recebe. Aula 0003
SAST
Static Application Security Testing: analisa o código-fonte sem executá-lo, em busca de padrões perigosos conhecidos. Aula 0003
SCA
Software Composition Analysis: compara as bibliotecas dos seus lockfiles com um banco de vulnerabilidades conhecidas. O resultado muda com o tempo, mesmo sem commit novo. Aula 0004
SCP (service control policy)
Uma política da AWS Organization que define o máximo que qualquer identidade de uma conta pode fazer, até a de administrador. Na conta do EduRAG, as SCPs são da AWS e negam, por exemplo, criar provedor OIDC (iam:*Provider*). Aula 0011 (registro 0013)
SHA (de commit)
O identificador de 40 caracteres de um commit. Numa action, @<sha> é imutável; já uma tag pode ser movida. Em tag anotada, vale o SHA da linha com ^{}. Aulas 0004, 0005
Segredo
Qualquer valor que dá acesso a algo: senha, chave de API, token, chave privada. Aula 0002
Severidade
O peso que uma regra dá ao achado (no Semgrep: INFO, WARNING, ERROR). Um portão pode barrar só a partir de uma severidade. Aula 0003
Rollback
Voltar para a versão anterior quando um deploy quebra. Exige que a versão anterior tenha um nome fixo, como a tag por SHA. Aula 0008
Security group
O firewall de uma instância na AWS: regras de entrada e de saída, só de liberação. O do EduRAG não tem entrada nenhuma e tem uma saída, TCP 443. Criado pelo Terraform, ele nasce sem a saída padrão. Aula 0013
Session Manager (SSM)
O serviço da AWS que abre sessão e túnel até uma instância sem SSH e sem porta de entrada: o agente na máquina chama a AWS de dentro para fora. No Windows, precisa do plugin session-manager-plugin. Aulas 0011 e 0013
State (Terraform)
O arquivo que liga cada objeto real da conta ao seu bloco no código. É texto puro: valor secreto em recurso vai parar nele. Fica num bucket S3 versionado, nunca no git. Aula 0011
Superfície de ataque
Tudo o que um atacante pode tentar explorar: cada pacote, porta e binário a mais. A imagem slim tem menos superfície que a completa. Aula 0006
SQL injection
Quando um valor vindo de fora é colado no texto da consulta e passa a ser interpretado como SQL. A defesa é passar o valor como parâmetro, separado do comando (CWE-89). Aula 0003
Teto de gastos (spend limit)
O máximo que a organização ou um workspace pode gastar na API da Anthropic por mês. Ao estourar, as chamadas falham até o mês virar ou o teto subir. É a última camada contra o gasto, porque não depende do código. Aula 0009
Trava do state (state lock)
Impede que dois comandos mexam no state ao mesmo tempo. No backend S3, é um objeto <key>.tflock criado com use_lockfile = true; o segundo comando falha com "Error acquiring the state lock". Aula 0012
Túnel do SSM (port forwarding)
Uma sessão do Session Manager com o documento AWS-StartPortForwardingSession: uma porta do seu computador passa a chegar numa porta da instância, sem porta de entrada aberta. É por ele que se abre a interface e o Grafana. Aula 0013
user_data
O script entregue à instância no lançamento. Roda como root, uma vez, no primeiro boot, e deixa o log em /var/log/cloud-init-output.log. No EduRAG, instala o Docker e o plugin do compose. Aula 0013
Usuário IAM
Uma identidade criada dentro da conta, com permissões dadas por políticas. No roteiro original, teria MFA e AdministratorAccess, e nenhuma access key. Na conta do EduRAG, uma SCP impede dar senha de console a ele, e o papel fica com o AWS Builder ID. Aula 0011
Varredura de histórico
Uma análise de todos os commits do repositório, e não só dos novos. Feita uma vez, descobre se algo já vazou. Aula 0002
Workspace (Anthropic)
Uma divisão dentro da organização no Console, com chaves, membros e limites próprios. A chave criada num workspace só age nele. O Default Workspace não aceita teto de gastos. Aula 0009
