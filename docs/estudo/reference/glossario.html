Referência · termos usados nas aulas

Glossário

As aulas usam estes termos sempre com este sentido.

Bypass list
Quem pode ignorar as regras de um ruleset. No protege-main, fica vazia. Aula 0001
Check obrigatório (required status check)
Um job da CI que precisa ficar verde para o merge ser liberado. É identificado pelo id do job no workflow. Aula 0001
Entropia
O quanto um texto parece aleatório. O gitleaks a usa para separar chaves reais de textos comuns que casam com a mesma expressão regular. Aula 0002
Falso positivo
Um achado de ferramenta de segurança que não é problema de verdade. Só deve ser suprimido com uma justificativa escrita. Aula 0002
Fingerprint
A identificação única de um achado do gitleaks (commit:arquivo:regra:linha). É o que vai no .gitleaksignore. Aula 0002
Menor privilégio
Dar a cada peça só as permissões de que ela precisa. Num workflow, é o bloco permissions. Aula 0002
Modo estrito
A regra "Require branches to be up to date": a branch do PR precisa estar atualizada com a main antes do merge. Aula 0001
Portão (gate)
Uma verificação que bloqueia, e não só avisa. Uma ferramenta vira portão quando o job dela entra nos checks obrigatórios. Aulas 0001, 0002
Revogar
Invalidar uma chave no serviço que a emitiu. É o primeiro passo diante de um segredo vazado. Aula 0002
Ruleset
Uma lista nomeada de regras que o GitHub aplica a branches escolhidas. Vários rulesets se somam. Aula 0001
Segredo
Qualquer valor que dá acesso a algo: senha, chave de API, token, chave privada. Aula 0002
Varredura de histórico
Uma análise de todos os commits do repositório, e não só dos novos. Feita uma vez, descobre se algo já vazou. Aula 0002
