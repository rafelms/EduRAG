Em 23/10, com a base 1.29 (Alpine 3.23.4), o front tinha 44 HIGH com correção; a troca de base pelo Dependabot (PR #19) levou para 3. O api não mudou.

Para as provas: nginx-unprivileged:1.21-alpine (Alpine 3.15.4, fim de suporte) dá 9 CRITICAL com correção e ainda constrói; remover o USER do Dockerfile da API faz o id -u devolver 0. A base python:3.9 tem CRITICAL, mas não serve de prova: o uv sync exige Python 3.12 e o build quebra antes do scan.

Multi-stage

Só o último FROM vira a imagem entregue. O estágio builder (Node, npm, uv) só entrega arquivos por COPY --from=builder e não aparece no scan.
